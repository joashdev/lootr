Research Report

UI Layouts, Navigation & Visual Design of Modern Personal Finance Apps

A pattern-by-pattern analysis of Copilot, Monarch, YNAB, PocketGuard, Maybe, Lunch Money and other notable apps, with recommendations for a beginner-focused Flutter app.

Scope & Methodology

This report is based on the public marketing sites, App Store listings, GitHub repositories and help-center documentation for each product. I captured screenshots where they were publicly available and inferred navigation/UX patterns from feature descriptions and user reviews. Maybe Finance (maybe.co) blocked direct fetching, so its section relies on the open-source GitHub repository and prior public knowledge.

Cross-App Pattern Summary

Navigation

  • Bottom tab bar is the dominant mobile pattern (4-5 top-level tabs).
  • Web apps lean on collapsible left sidebars with secondary top tabs.
  • Budget and Transactions are almost always top-level.
  • Add-transaction moves from bottom-center tab to a floating action button in newer redesigns.

Dashboard Cards

  • Large headline number (net worth, safe-to-spend, ready to assign).
  • Secondary cards: recent transactions, budget progress, upcoming bills, investments.
  • Progress bars and mini line charts are preferred over dense tables.

Transactions

  • Chronological list grouped by date with merchant logos and category icons.
  • Swipe actions for review, edit, categorize and split.
  • Search plus chip filters for account, category and date range.

Budgeting

  • Progress bars per category with color-coded status (green on-track, yellow close, red over).
  • Rollover and goal-target indicators are increasingly common.
  • One-number “safe to spend” views help beginners avoid overwhelm.

1. Apple-First, Clean Design

Copilot Money

copilot.money · iOS, iPad, Mac, Web · Subscription

Open site

Navigation: Native iOS bottom tab bar. Core tabs are typically Home (dashboard), Transactions, Budget, Net Worth and Settings. A dedicated chat/AI assistant (“Copilot Agent”) is accessible from the top-right or a floating prompt.

Dashboard: A single scrollable feed of cards: a large “spending line” chart for the month, pending refunds/upcoming bills, budget health, recent transactions and investment performance. Apple-style large titles, generous whitespace and rounded cards.

Transactions: Unified list auto-categorized by machine learning. Each row shows merchant name, category icon, amount and a “reviewed” state. Users can split charges, add tags and attach notes.

Budget: Category cards with horizontal progress bars and rollover amounts. Green “under budget” labels and red “over budget” labels are prominent. Cash flow is surfaced as income vs. spending vs. net income.

Accounts: Account list grouped by institution with real-time balances. Net worth total sits at the top. Investments include allocation charts and live price updates.

Modals/Sheets: iOS-style sheets slide up for transaction details, budget creation and account linking. Demo mode lets new users explore without connecting banks.

Colors & Visual Hierarchy: Light/dark mode, iOS system colors, purple/indigo accents, green for surplus, red for overspending, large bold totals, muted secondary labels.

Mobile Patterns: Native gestures (swipe to review/edit), haptics, home-screen widgets, Apple Watch support, Liquid Glass visual refresh on iOS 26.

Beginner UX: Excellent for beginners because automation does the heavy lifting. Downsides: subscription cost, U.S.-only institutions, occasional sync/data-date issues and limited search/export options.

Key Components

  • Large-title dashboard
  • Spending-line chart card
  • Category progress bars
  • Subscription-tracking card
  • iOS sheet modals
  • Home-screen widgets

2. Web + Mobile, Highly Customizable

Monarch Money

monarchmoney.com · Web, iOS, Android · Subscription

Open site

Navigation: Web: collapsible left sidebar (Dashboard, Transactions, Budget, Cash Flow, Goals, Reports, Recurring, Accounts, Settings) plus top tabs inside sections. Mobile: bottom tab bar with Dashboard, Transactions, Budget, Cash Flow and More.

Dashboard: Fully customizable widget grid. Users drag and drop cards for net worth, recent transactions, budget progress, investment performance, upcoming expenses and savings goals. A monthly-review card can be swiped through for quick insights.

Transactions: One clean, searchable list across all accounts. AI categorization plus manual overrides. Swipe to review or edit. Filter by account, category, date, amount, merchant and review status.

Budget: Two modes: Category Budgeting (traditional envelopes) and Flex Budgeting (one “flexible spending” number after fixed/non-monthly buckets). Category groups use emojis. Progress bars, rollover support and future forecasting are built in.

Accounts: Accounts grouped by type (Cash, Credit, Loans, Investments, Real Estate). Zillow integration for property values. Net-worth chart over time.

Modals/Sheets: Slide-up sheets for transaction editing, receipt uploads, budget adjustments, recurring bill details and filters. Recent updates added AI assistant chat threads and bulk receipt uploads.

Colors & Visual Hierarchy: Clean white surfaces, rounded 2xl cards, purple/indigo primary, green/red semantic colors, bold monetary figures, subtle gray labels. Consistent border-radius and soft shadows.

Mobile Patterns: Bottom navigation, home-screen widgets, Siri Shortcuts, Quick Action receipt scanning, biometric auth, drag-and-drop dashboard customization on larger screens.

Beginner UX: Strong for users who want control; onboarding auto-categorizes past transactions and suggests budgets. The breadth of options can feel overwhelming for absolute beginners, and the subscription is required after a short trial.

3. Proactive Envelope Budgeting

YNAB (You Need A Budget)

ynab.com · Web, iOS, Android, Apple Watch · Subscription

Open site

Navigation: Web: left sidebar with Budget, Reflect, Accounts, Reports and Goals; the budget is the canonical view. Mobile: bottom tab bar with Home, Budget, Accounts, Reports and a floating “Add Transaction” FAB. The recent redesign introduced a Home tab that aggregates notifications and insights.

Dashboard/Home: Home tab shows actionable notifications (new transactions, overspending, bank reconnect), account balances, goal progress and spending insights. The Budget screen remains the core dashboard for many users.

Transactions: Account-register style lists. Each row shows payee, category, outflow/inflow, cleared/uncleared status and flag color. Strong search and filters by payee, category, memo and date. Manual entry is first-class.

Budget: Envelope grid. Categories show “Assigned,” “Activity” and “Available.” Color coding is central: green = funded, yellow = underfunded target, red = overspent. Users tap a category to assign money or move funds. Target/progress bars appear for goals.

Accounts: Account list with current and cleared balances. Reconciliation workflow is a standout feature. Credit-card payments get their own payment category.

Modals/Sheets: Transaction editor (recently redesigned with clearer type selection), move-money popover, category target setup, loan calculator, split-transaction sheet and report filters.

Colors & Visual Hierarchy: Signature “blurple” purple/blue primary, green for available/positive, red for overspending, yellow/orange for warnings, clean sans-serif typography. High contrast and strong accessibility support.

Mobile Patterns: Floating add-transaction FAB, bottom navigation, widgets, Siri integration, dark mode, strong VoiceOver/Voice Control support, swipe to approve, haptic feedback.

Beginner UX: The methodology is powerful but has a learning curve. YNAB mitigates this with a 34-day free trial, live workshops, guided setup and extensive help docs. Best for beginners willing to invest time; not ideal for users wanting a zero-effort overview.

4. Simplicity & Safe-to-Spend

PocketGuard

pocketguard.com · Web, iOS, Android · Freemium

Open site

Navigation: Mobile: bottom tab bar with Plan (budget/cash flow), Transactions, Insights, Goals and Profile. Web: top navigation with sections for Plan, Transactions, Insights, Debt, Net Worth and Settings.

Dashboard: Centered around a single headline number: “In My Pocket” — the amount safe to spend after bills, goals and necessities. Supporting cards show budget health, net worth, upcoming bills and cash-flow projection.

Transactions: Unified list from linked accounts plus manually entered cash transactions. Auto-categorization with custom rules. Pending transactions are visible. Search and filter by account, category, merchant and date. Hashtags enable custom spending reports.

Budget: Spreadsheet-like category list with emojis, budget limits and progress bars. Users get notified at 50% spend in a category. Budgets reset monthly automatically. Debt-payoff planner and savings goals are integrated.

Accounts: Linked accounts list grouped by type; net-worth tracker and property-value support. Recurring bills and subscriptions are shown in a calendar or list.

Modals/Sheets: Bottom sheets for transaction details, category editing, rule creation, goal setup and budget scenario testing.

Colors & Visual Hierarchy: Dark-first marketing site; app supports light/dark. Teal/cyan accent, green/red semantics, high-contrast numbers, rounded cards.

Mobile Patterns: Bottom navigation, push notifications for bills and budget thresholds, QR install flow on the site, simple onboarding focused on the one “In My Pocket” number.

Beginner UX: One of the best for beginners. The “In My Pocket” abstraction removes complexity, automation is strong, and the app offers a PFM course and budget calculator. Power users may find it less flexible than Monarch or YNAB.

5. Open Source, Self-Hostable

Maybe Finance

maybe.co / github.com/maybe-finance/maybe · Web (self-hosted) · Open source

Open repo

Navigation: Web sidebar: Dashboard, Accounts, Transactions, Budget, Investments, Net Worth, Settings. No native mobile app; the responsive web UI is the mobile experience.

Dashboard: Minimal overview of net worth, account balances, recent transactions and portfolio allocation. Designed for clarity rather than dense widgets.

Transactions: Register list with categories and tags. Supports manual entry, CSV upload, bank sync and a developer API. Search and filters are present but simpler than commercial competitors.

Budget: Category budgets with progress bars. Less sophisticated rollover/target logic than Monarch or YNAB.

Accounts: Grouped account cards by type with balances. Real-estate tracking by address.

Modals/Sheets: Modal forms for adding/editing transactions, accounts and categories. Because it is web-first, sheets are center/right-side modals rather than native bottom sheets.

Colors & Visual Hierarchy: Neutral, minimalist palette with a single accent color (likely blue/indigo). Clean typography, low visual noise.

Mobile Patterns: Limited native mobile patterns. Touch-friendly buttons and responsive tables, but no gestures, widgets or bottom navigation.

Beginner UX: Great for privacy-conscious or technical users who want free self-hosting. Bad for typical beginners: requires setup, archived by the maintainer in mid-2025, no dedicated mobile app and fewer guardrails.

6. Indie, Spreadsheet-Like

Lunch Money

lunchmoney.app · Web-first + companion mobile app · Subscription

Open site

Navigation: Web: left sidebar with Dashboard, Transactions, Budget, Calendar, Net Worth, Stats & Trends, Analytics, Rules and Settings. Mobile companion: simplified bottom or drawer navigation.

Dashboard: Big-picture dashboard with net-worth chart, account balances, upcoming recurring items, budget overview and recent transactions. Emphasis on “see the big picture.”

Transactions: Unified, searchable list. Users can split, group, tag and categorize. Strong rules engine auto-categorizes based on merchant/description. Filter by category, tag, account, date and amount.

Budget: Monthly category budgets with progress bars. Color-coded categories and tags. Supports multi-currency budgets aggregated into a home currency.

Accounts: Multi-currency accounts grouped by type. Net worth tracked month over month. Crypto wallets and ledgers can be connected.

Modals/Sheets: Web modals for transaction editing, splits, rule creation and category/tag management. Mobile uses native screens.

Colors & Visual Hierarchy: Light, friendly palette, soft accent colors, mascot branding, clean readable tables that feel spreadsheet-like but polished.

Mobile Patterns: Web-first; companion app is secondary. Less reliance on native gestures, but responsive tables and clear touch targets.

Beginner UX: Approachable and “just works” according to user testimonials. Multi-currency is a standout for expats and digital nomads. The rules engine and spreadsheet-style tables may intimidate absolute beginners.

Other Notable Modern Apps

Goodbudget

goodbudget.com · Envelope budgeting, manual entry, shared budgets.

Simple visual “fill envelopes” interface with progress rings, color-coded categories and a family-sharing model. Best for users who want a digital version of cash envelopes.

Simplifi by Quicken

simplifi.money · Dashboard cards, watchlists, spending plan.

Top tabs for Dashboard, Transactions, Spending Plan, Reports and Accounts. Heavy use of cards and watchlists. Good for users transitioning from Mint.

Empower (formerly Personal Capital)

empower.com · Net worth + retirement/investment focus.

Net-worth dashboard, portfolio allocation, retirement planner and cash-flow calendar. Investment visualization is more advanced than budgeting.

Rocket Money

rocketmoney.com · Subscription cancellation focus.

Clean list of recurring charges, cancellation actions, spending by category and net-worth tracking. Strong empty-state illustrations and clear CTAs.

Patterns to Adapt for a Beginner-Focused Flutter App

Based on the analysis above, the following patterns strike the best balance between simplicity and usefulness for first-time budgeters.

1. Bottom navigation, 4-5 tabs

Use Home, Transactions, Budget and More/Profile. Keep the budget and transactions always one tap away. Avoid hamburger menus as primary navigation.

2. One headline number on Home

Follow PocketGuard’s “In My Pocket” model: show the amount safe to spend today, then reveal category breakdowns on tap. This reduces anxiety and cognitive load.

3. Card-based dashboard with progress bars

Use large rounded cards for net worth/cash flow, budget progress and upcoming bills. Horizontal progress bars with color thresholds are instantly scannable.

4. Friendly transaction list

Group by date, show merchant icons or initials, category chips and amount. Add pull-to-refresh, swipe-to-edit/delete and a persistent search bar with filter chips.

5. Bottom sheets for detail & creation

Use Flutter DraggableScrollableSheet or modal bottom sheets for transaction forms, category pickers and filters. Keeps context visible and feels native.

6. Empty states with a clear first action

Illustrate empty budgets, accounts and transactions with a short explanation and a primary button. Add demo/sample data so users can explore before linking banks.

7. Simple data visualization

Start with a donut chart for spending by category and a line chart for net worth over time. Avoid complex reports until users ask for them.

8. Semantic color system

Reserve green for on-track/surplus, amber for warnings, red for overspending. Pair colors with icons or text labels for accessibility.

9. Guided onboarding with defaults

Pre-populate common categories, ask for a starting balance, let users add one manual transaction, then optionally connect a bank. Use tooltips on first use.

10. Native-feeling mobile details

Add haptic feedback when budgets hit thresholds, a floating action button for adding transactions, and light/dark mode from day one. Keep tablet layouts as a two-pane master-detail view.
