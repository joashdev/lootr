Gaps & notes

  • Camera / OCR scan flow — not captured. No camera on the simulator; the /scan route opens the device camera so it cannot be driven headlessly. Documented gap only.
  • AI quick-add parse — not captured. The quick-add sheet's natural-language parse needs AI settings / network; skipped to avoid blocking the run.
  • Add-transaction sheet — not captured this pass. It is reachable via the floating "+" island (Quick Actions sheet), but was left out to keep the run deterministic; the test is structured so a frame can be added later.
  • Recurring / Reports / Insights / Categories / Payees / Households / Settings — exist under the More tab but are out of the requested core scope.

Real-app observations (vs. a naive wireframe guess)

  • Onboarding is 4 steps, not a single form: three intro slides (Welcome / Track every peso / Plan your spending) then a profile-setup page. A "Skip" link jumps straight to setup with demo data forced OFF.
  • The setup page has a display name (required), a currency dropdown defaulting to PHP, and the Load demo data toggle (default ON). The finish button reads "Get Started", intermediate ones read "Next".
  • Bottom navigation is a floating glass pill with four tabs (Home / Transactions / Budgets / More) plus a separate "+" island — not a standard Material bottom bar.
  • Accounts, Goals, and Debts live under the More tab (pushed routes), not as top-level tabs.
  • Empty-state copy is specific and CTA-driven: Transactions says "No transactions yet / Add an account first…" with an Add Account button (it correctly detects there are no accounts), Accounts "No accounts yet / Add Account", Goals "No goals yet / Add Goal".
  • Seeded dashboard surfaces a "Safe to spend" headline (₱1,251 from ₱8,000 income), a Net worth line chart (₱14,800, +20.5%), and an Accounts carousel (Cash ₱2,500, Bank ₱15,000).
  • The seeded Debts entry renders as "Friend · You borrowed · ACTIVE · ₱3000 of ₱5000".

Design polish pass #1 — what changed

  • Palette. Brand moved from periwinkle #5C64CC to muted denim #3E6CB3. Expenses are now neutral ink instead of coral, income stays green, and red is reserved for true alerts (over-budget, errors) — visible on the Budgets screen where only the over-budget category turns red.
  • Header. The greeting is now an eyebrow above the name ("Good afternoon" / "Alex" / date) — a long display name no longer gets truncated by the time-of-day prefix.
  • Numbers. Summary figures (safe-to-spend, net worth, account cards, income/expense strip) drop centavos and switch to compact ₱1.2M / ₱24.0M / ₱1.2B above ₱1,000,000; transaction rows and detail screens keep exact two-decimal values. Currency symbol now follows the account's currency code, not a hard-coded ₱.
  • Note: demo balances top out around ₱15,000, so the compact M/B form is logic-only here — it does not visibly appear in these captures.
