# Security Policy

Lootr handles sensitive financial information even though it is not a banking
service. Please avoid public disclosure until a vulnerability has been reviewed.

## Report a vulnerability privately

Use
[GitHub private vulnerability reporting](https://github.com/joashdev/lootr/security/advisories/new).
Include the affected version, impact, and minimal reproduction steps.

Do not attach a real Lootr database, backup, export, receipt, access token, or
other personal financial data. Use synthetic data for reproductions.

Ordinary functional bugs belong in the public
[issue tracker](https://github.com/joashdev/lootr/issues).

## Supported versions

During the `0.x` alpha period, only the newest GitHub prerelease is supported.
Security fixes may require upgrading rather than patching older alpha builds.
